Access & options

For private repos, use a fine-grained PAT with Contents: Read-only for the selected repo. Kept in tab memory, sent only to api.github.com. Never saved or shared.

Only preview trusted code. Scripts cannot access Siteview's token or storage, but can read files at the selected commit and send them to external services. Forms, popups and top navigation are blocked.

Prebuilt static sites only. Relative assets and ES modules work. No build tools, servers, XHR, workers, or computed asset paths. Share links open this viewer, not a CDN endpoint.
